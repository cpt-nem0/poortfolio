# Layout v2 — Common Area, Workstation Room, Genkan, Stair-Room Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure the ground floor per the layout-v2 spec + Rohan's 2026-08-09 workstation excalidraw: the current workspace becomes the COMMON AREA (stairs stay, gets a basement-stair stub), a new WORKSTATION room appears behind it (whole work interior migrates), a GENKAN entry strip attaches to the south, and the roof gets an enclosed STAIR-ROOM — with framed openings everywhere and stations retargeted.

**Architecture:** All geometry flows from `layout.ts` rect consts (single source of truth; meshes derive). The workstation is a new camera AREA (dollhouse can't see behind the front row): crossing the door threshold swaps areas like the ladder does, but position-triggered. Discrete-room rendering extends naturally — an area renders only its own rooms. Spec: `docs/superpowers/specs/2026-07-18-house-layout-v2.md` (incl. the 2026-08-09 Resolutions section — binding).

**Tech Stack:** react-three-fiber 9 / three 0.185 / drei 10 / zustand / vitest (alias `@`→`./src`).

## Global Constraints

- **PR FLOW (site is LIVE):** all work happens on branch `3am-layout-v2`. Agents NEVER commit or stage — changes stay unstaged; Rohan commits at checkpoints, pushes, and owns the PR. Vercel PR preview = his feel-check surface. NOTHING merges to main until the final whole-branch review + his walkthrough pass.
- Music nook is STYLE-LOCKED (x16–22): no changes. Bedroom+engawa: no changes beyond shared-wall door framing.
- Colliders in `layout.ts` are the single source of truth — meshes derive positions from the rect consts, never re-hardcode.
- NO invisible light sources — every light nests inside its visible fixture (rotation-aware; this bug shipped 3×). Shadow budget stays exactly 2 casters (both music nook). `Scene.tsx` ambient (0.3 `#8d9bd6`) + directional (0.4 `#7684c9`) untouchable.
- ≥6mm offsets between stacked coplanar surfaces (4mm absolute floor). No roofs/overheads over walkable areas visible to a top-down camera (black-lid bug); the stair-room is on the ROOF area where its own camera frames it — verify it doesn't lid the terrace view.
- Camera law: north walls = detail; east/west = mass/light; south furniture faces away. Applies per-area (workstation has its own north).
- Discrete rendering: an area renders only its rooms; within ground, the 2-room nearest-doorway cap (0.4m hysteresis) stays as-is.
- Only ONE texture-generator agent at a time; every generator function needs a JOBS/TILES entry and vice versa.
- Every task's gates before reporting: `pnpm test`, `npx tsc --noEmit` (0), `pnpm lint` (0 errors; 13 pre-existing script warnings fine), `pnpm build` (cp -R clone to scratchpad if the dev server holds `.next`; symlinked node_modules panics Turbopack).
- Tests must be able to fail: sweep LIVE data (`ground.furniture` etc.), prove one forced-red per new test file. Baseline at branch time: 160 tests.
- Copy is lowercase-casual; proper nouns keep casing.
